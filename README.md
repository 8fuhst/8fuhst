## Moin!
I'm Noah, and I currently work as a Junior Cloud Engineer at DIE ZEIT in Hamburg, Germany. I love working on scripts, automations, and anything that makes your life easier and solves real problems. When coding, I like working with Python or Bash for my scripting needs. Apart from that, designing large systems is fun for me, alongside with the respective orchestration via Kubernetes, Docker, or similar tools. The most fun part however is checking your systems in terms of security, availability, robustness, etc. - after all, its fun to build a tower, but more fun to kick one down! :)

These are some of the languages, tools and libraries I regularly use:

🗣️ Languages: Python, Terraform/opentofu, Bash, Go, Java - at some point I'd like to try Rust, C or some other low-level language

🔧 Tools: Kubernetes, GCP, Docker, Terragrunt, Flux CD, HashiCorp Vault, GitHub Actions, Prometheus, Grafana

💾 Databases: MongoDB, Postgres, Elastic
